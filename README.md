# מערכת שאלון פתיחה + חתימת תקנון

מערכת חתימה דיגיטלית חינמית למתאמנים חדשים - קובץ HTML יחיד המתארח ב-Netlify, ללא תשלום לשירות חתימה חיצוני.

## איך זה עובד
- כל מסלול מקבל קישור ייעודי: `?plan=NAME`
- הלקוח ממלא פרטים אישיים, שאלון בריאות, קורא את התקנון וחותם באצבע
- נוצר PDF אחד (הצהרת בריאות חתומה + תקנון מלא) שנשלח אוטומטית ל-Google Drive + Google Sheet

## מבנה תיקיות
- `assets/` - ספריות JS מקומיות (html2pdf.js, pdf-lib) ותמונת חתימת העסק
- `terms/` - קבצי PDF של התקנון לכל מסלול
